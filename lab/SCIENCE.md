# 보면 풀리는 과학 — 시리즈 기획안

모라구 채널 안의 과학 카테고리(재생목록 **보면 풀리는 과학**, 공개, 채널 홈 두 번째 섹션). 수학 갈래(보면 풀리는 수학)와 같은 `lab/` 에서 같은 도구로 만든다. 갈래 전체 규칙은 [CLAUDE.md](CLAUDE.md), 도구 · 수학 기록은 [CATEGORY.md](CATEGORY.md).

## 1. 한 줄 컨셉

**"화면이 곧 실험이다."** 시청자가 쇼츠를 보다가 **자기 눈 · 손 · 귀로 직접 결과를 확인**하고("진짜 사라지네?"), 바로 그 원리를 움직이는 그림으로 본다.

왜 잘 되나 (맹점 · 잔상 두 편에서 확인, 2026-10-23):
- 끝까지 봐야 실험이 끝난다 → 시청 지속.
- "나만 그런가?" → 댓글 · 공유가 생긴다.
- 결과가 화면에서 바로 확인되니 말이 적어도 된다 (음성 없이 자막 + 음악으로 충분).

## 2. 한 편의 틀 (55~59초, 1080×1920)

| 박자 | 길이 | 하는 일 |
|---|---|---|
| ① 훅 | 3~4초 | 글리치 제목(질문형) + 주제 그림 → 그림 속으로 줌 스루 |
| ② 준비 | 4~6초 | "무엇을 몇 초 보고 → 그다음 무엇을 본다" 를 작은 그림 두 개 + 화살표로. 필요한 안전 안내 한 줄 |
| ③ 테스트 | 10~20초 | 배경을 어둡게 덮고 표적만. **표적 둘레는 움직이지 않는다**. 위쪽에 카운트다운 칩, 아래 자막만 바뀐다 |
| ④ 확인 | 4~6초 | **전환 효과 없이 한 번에** 다음 화면으로 바꿔 화면에서 바로 결과가 보이게 → 그다음 "진짜 ○○도 봐요" |
| ⑤ 원리 | 12~16초 | 몸 속 그림(세포 · 신경 · 팀 줄다리기 등) 하나로. 개념은 하나만 |
| ⑥ 생활 예 | 0~5초 | 폭포 착시처럼 아는 장면 하나 (있으면) |
| ⑦ 정리 · 다음 | 5초 | 정리 카드 한 줄 + NEXT 예고 (다음 편 질문) |

- 자막은 두 줄 이하, 한 자막이 최소 2초는 머물게. 영어 자막은 `scripts/srt.mjs` 표에 같이 넣는다.
- 아래 20%(y > 580)는 쇼츠 UI 가 덮으니 비운다.

## 3. 안전 기준 (모든 편 공통)

- **깜빡임 · 번쩍임 금지**(광과민성). 도는 그림은 프레임마다 조금씩(몇 px) 부드럽게. 흰 화면으로 바뀌는 건 한 번까지.
- 어지러울 수 있는 편(소용돌이 등)은 "어지러우면 바로 멈추세요" 를 준비 단계와 설명란에 넣는다.
- 소리 편은 "소리를 작게" 안내. 아주 높은 음(모기 소리 테스트) · 큰 소리 금지.
- 눈을 누르거나 비비는 실험, 불 · 전기 · 약품 실험은 하지 않는다.
- 의학 진단처럼 말하지 않는다("안 되면 이상" 금지 — 화면 크기 · 거리에 따라 다를 수 있다고 안내).

## 4. 연출 키트

- `src/motion.tsx`: 배경(빛 덩어리 · 점 모눈), HUD(말머리 · 시리즈 진행 막대 — `brand: '보면 풀리는 과학'`), 자막 카드, 사선 와이프, 링 · 불꽃, 끝 카드, 효과음 큐(`cue`), 영어 자막 기록(`capLog`).
- `src/sci.tsx`: 준비 단계(작은 그림 + 화살표, `addSteps`), 카운트다운 칩(`addTimer`), 어둡게 덮기(`addDim`).
- `src/fx.tsx`: 글리치 제목, 원형 아이리스 전환, 줌 스루(`zoomInto` / `arrive`), 흔들림, 렌즈 빛줄기, 보케.

## 7. 한 편 만드는 절차

1. 주제의 사실 확인 (수치는 교과서 수준만), 이 문서 표에 줄 추가.
2. `src/scenes/<이름>.tsx` 작성 → `src/<이름>.ts` · `vite.config.ts` 목록 · **`src/<이름>.meta` 복사**(없으면 가로 · PNG 로 렌더됨).
3. `node scripts/bgm.mjs <이름> --silent` → 편집기에서 장면을 한 번 돌려 큐 생성 → 길이(60초 이하) · 자막 머무는 시간 확인.
4. `scripts/en/<이름>.json` ({EN, NEXT, TITLE}) 에 영어 번역 · NEXT · (글리치 제목이면) TITLE 추가 → `node scripts/srt.mjs <이름>` · `node scripts/bgm.mjs <이름>`.
5. 렌더 (별도 Chrome 창 puppeteer 방식, CATEGORY.md 6-3) → 2초 간격 장면표로 겹침 · 잘림 확인.

- [ ] **숫자 기억 (청킹)** — 숫자 9~10개를 3초 보여 주고 따라 쓰게 함 → 같은 숫자를 3 · 3 · 4 로 묶어서 다시. 원리: 잠깐 기억하는 칸은 몇 개뿐, 묶으면 한 칸에 더 담긴다. **"7개" 같은 숫자는 말하지 않는다** (연구마다 다름).

- [ ] **패스 세기 (무주의맹)** — 도형 공 패스 횟수를 세는 동안 다른 도형 하나가 천천히 지나감 → "몇 번?" 다음에 "혹시 뭐가 지나간 거 봤어요?" 원리: 집중한 것 말고는 잘 안 보인다. 화면은 코드 도형만(사람 영상 · 고릴라 그림 안 씀).

### 8-3. 피부의 비밀 (새 시리즈, 3편) — 「내 몸 실험실」 이어서

- [ ] **코가 두 개? (아리스토텔레스 착각)** — 검지와 중지를 꼬아 그 사이로 코끝 · 구슬을 만지면 두 개로 느껴짐. 원리: 뇌는 손가락이 늘 제자리에 있다고 가정한다.
- [ ] **한 점일까 두 점일까 (두 점 구분)** — 연필 두 자루를 붙여 쥐고 **뭉툭한 쪽**으로 손끝 · 팔뚝을 살짝 눌러 보기(친구가 눌러 줌, 눈 감기). 원리: 부위마다 감각 세포의 빽빽함이 다르다 (뇌 속 몸 지도). 이쑤시개 · 핀처럼 뾰족한 것은 쓰지 않는다. 손끝 몇 mm · 팔뚝 몇 cm 같은 수치는 교과서 수준으로 확인될 때만.
- [ ] **미지근한 물의 배신 (온도 순응)** — 한 손은 찬물, 한 손은 따뜻한 물에 30초 → 두 손을 미지근한 물에. 한 물이 차갑게도, 따뜻하게도 느껴짐. 원리: 피부는 온도 자체보다 "변화"를 느낀다. 준비 단계와 설명란에 **"뜨거운 물 금지, 따뜻한 수돗물만 · 어른과 함께"**.
