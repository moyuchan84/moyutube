# 모답맨 — 에피소드 빌더

2026-10-23 사용자가 확정한 qna 포맷. 이전 포맷(아빠의 회상 · 긴 나레이션 · 8분 · 7박자)은 루즈해서 시청이 끊겼다.
모답맨은 **3분 안쪽, 2~3초마다 화면이 바뀌는 모션 편집, 병맛, 하지만 내용의 본질(정확한 사실)은 그대로**다.

**기준 예시 — 8편 `content/ep08f-modapman/script/script.json` · `content/ep08f-modapman/script/motion.json` · `video/out/motion/ep08f-modapman.mp4` (렌더 결과, git 제외).**
새 편을 쓰기 전에 이 셋을 먼저 읽는다.

## 고정 규칙

- **시리즈 이름은 「모답맨」.** 아빠가 콜드 오픈에서 "오답, 하나. 저는 모답맨입니다."로 자기소개하고, 끝은 "오답, N. 역시, 모답맨." 류로 닫는다.
- **오답 카운터가 편 전체를 꿴다.** 아빠 · 엄마 · 제삼의 인물 · (반전의) 아빠가 틀릴 때마다 정색한 나레이션 "오답, 둘." + 화면 구석 正 카운터가 한 획씩 는다. 보통 3~4개.
- **관계는 부모-자녀.** 교사-학생 어휘("우리 반", "가르치다") 금지. 틀리는 건 어른이고, 아이는 핵심을 찌르는 질문만 한다.
- **집 밖에서, 제삼의 인물과.** 정답 담당(경찰관 · 약사 · 할머니 …)은 정색한 한 줄 태클 담당 — "안 뛰세요." 같은.
- **분량 3분 안쪽 (2:40~3:00).** 대사 45~55줄, 공백 뺀 900~1,100자. 한 줄 15~20자, 길어도 35자.
- **나레이션은 설명하지 않는다.** 정색한 진행자 한 줄만 ("사건 개요. 아이 자전거 실종. 장소, 지구대." "메모했습니다. 손바닥에."). 상황은 대사로 보여 준다.
- **설명은 라운드제.** "딱 세 판만 하죠." → ROUND 1 · 2 · 3, 라운드마다 개념 하나. 각 라운드 = 한 줄 정의 + 화면 글자 카드 + 오답 인물의 반응 한 줄.
- **아빠의 상상 장면을 최소 1번.** 틀린 설명을 그대로 그림으로 보여 주고(분홍 "아빠의 상상" 화면) 정답 인물의 태클로 깬다.
- **아이 눈높이 박자에는 농담 없음.** 채널의 진심이 전달되는 자리 — 따뜻하고 조금 느리게, 효과음 없이. (기존 6번 박자 정신 그대로)
- **반전 + 카운터 회수로 끝.** 마지막 오답은 다시 아빠.
- **사실은 확인된 것만.** 한 곳 보도뿐인 숫자는 빼고 말한다. 법 · 의료는 끝 화면 주석으로 "일반 설명, 개별 상담은 전문가에게".
- **AI 티 나는 문장 금지.** "알아보겠습니다", "결론적으로" 금지. 문장 길이는 들쭉날쭉하게.
- **민감한 소재(몸 · 성 · 숙박 통념)**: 당황은 코미디로만, 이유를 대사로 풀지 않는다, 아이 대사는 순수하게, 몸은 그리지 않는다. 민감한 단어는 대사에만, 제목 · 썸네일 · 화면 글자에는 쓰지 않는다.
- **정치 · 종교 · 제도 개편**은 찬반을 말하지 않는다. "~해서 좋다는 쪽, ~가 걱정이라는 쪽. 지켜볼 일입니다." 한 줄.

## 구조 (약 3분)

| 박자 | 시간 | 내용 |
|---|---|---|
| 콜드 오픈 | 0:00–0:15 | 아이 질문 → 아빠의 자신만만한 오답(상상 장면) → 정답 인물의 정정 → "…네?" 크래시 줌 → **"오답, 하나. 저는 모답맨입니다."** → 타이틀 카드 |
| 사건 개요 | 0:15–0:25 | 나레이션 한두 줄로 장소 · 상황. 오답 후보(제삼의 인물) 등장 + "오답 후보" 이름표 |
| 오답 퍼레이드 | 0:25–0:45 | 엄마 · 주변 인물의 흔한 오해 → 정정 → "오답, 둘." · 아이의 핵심 질문 · 아빠의 망상 → 한 줄 태클 |
| 정답 라운드 | 0:45–2:15 | "딱 세 판만 하죠." ROUND 1~3. 오해가 풀리는 인물에게 "오답, 셋." |
| 아이 눈높이 | 2:15–2:35 | 농담 없음. 아이에게 다시 설명 · 아이의 작은 행동으로 마무리 |
| 반전 | 2:35–2:55 | 사건의 반전 → 아이의 한마디 → "오답, 넷. 역시, 모답맨." → 끝 화면(주석) |

## 그림 기준 — **[qna/ART_GUIDE.md](../../../ART_GUIDE.md) 를 먼저 읽고 그대로 따른다**

- 글자 프롬프트만으로 그리지 않는다. 첨부 목록은 코드(`attachPlan`)가 정하고 `GEMINI_PROMPTS.md` 의 "첨부 N장" 줄에 나온다 — 빠짐없이, 그 순서로 올린다.
- `art.json` 을 쓸 때: 손님 `cast` 는 `"the <역할>: …"` 로 시작, 장면 · 상상 · 소품 속에 같이 나오는 사람은 전부 `"people": [...]` 에, 설명(`desc`)은 영어로 포즈 · 표정만.
- `npm run prompts -- epNN` 결과에 ⚠️ 가 하나라도 있으면 그림을 뽑지 않는다. 새 손님은 `normal` 부터 뽑아 확정.
- 첨부 사본은 `npm run artrefs -- epNN`, 뽑은 뒤 비교는 `npm run artreview -- epNN` (기준 그림과 나란히 → `jobs/review.json` 에 ok/redo).
- 시그니처 당황 포즈(공통 컷인)를 재사용한다: 아빠 `common/cutin/dad-sig-1~3` · 엄마 `mom-sig-1~4` + `mom-sig-scream` · 아이 `kid-sig`.

## 산출물 (이 순서로)

1. **자료조사 메모** — 기원 · 갈라진 지점 · 오늘날 오해(= 오답 후보 목록) · 출처와 확인 상태. 오답 후보 3~4개를 누가 말할지 정한다.
2. **대본** — `content/<편>/script/script.json`. 컷마다 목소리 둘까지(`voice.json`), 숫자는 `tts` 로 한글 읽기, 줄마다 `en`(영어 자막). `"speed": 1.2`, `"rawVoice": true`. 기획서 `.md` 에도 같은 대본.
3. **그림 목록** — `art.json`: 배경 2~3장, 인물 포즈, 얼굴 컷인(놀람 · 자신만만 · 정색), 소품 10장 안팎(라운드 카드 옆에 놓일 것), 상상 장면 배경 1장. 공통 그림(`content/_common/art`)부터 재사용.
4. **샷 편집 계획** — `content/<편>/script/motion.json` (아래 "샷 계획").
5. **제목 · 설명 · 태그** — 아래 "제목 짓기". 영어 제목(100자 안) · 설명도.
6. **썸네일** — 계획의 `thumb` (위 두 줄 + 작은 셋째 줄, 놀란 아빠 얼굴 + X + 정답 인물 + 오답 카운터).
7. **한 문장 정리** — 정답 라운드 끝 나레이션과 같은 문장.

## 샷 계획 (`content/<편>/script/motion.json`, 엔진은 `src/motion/Motion.tsx`)

- `beats` 하나 = 대사 한 줄(`line: "c03-1"`) 또는 대사 없는 장면(`hold: 프레임`). 대사 한 줄에 샷 1~3개(`at` 로 나눔).
- **2~3초마다 화면이 바뀐다.** 긴 대사는 샷을 2~3개로 쪼갠다. 같은 그림이 4초 넘게 머물지 않게.
- 전환 `in`: whip-l/r/u(휙 · 모션 블러) · zoom · spin · wipe(3색 사선) · iris · glitch · slam · smash(반전 번쩍) · flash.
- 카메라 `cam`: from/to [x, y, 배율], `roll`(기울기), `punch`(크래시 줌 프레임들), `ease: "snap"`.
- 장치: `freeze` + `tag`(멈춤 + 노란 이름표), `mark`(O/X), `tally`(正 카드), `loading`(진행 막대 n%), `jail`, `note`(※ 주석), 글자 `style`(slam · stamp · pop · type · shake · news), `fx`(lines · shake · imagine · docu · vhs · slowmo · mono).
- 오답이 나오는 박자에 `count: n` → 구석 카운터가 는다. 계획 맨 위 `"counter": "모답맨 오답"`.
- 효과음은 코드 합성(`scripts/sfx.mjs`): pop · stamp · pang · whoosh · boing · dudung · buzz(오답) · ding(정답) · scratch · slide · crash · tick · rewind · beep · stinger.
- 아이 눈높이 박자: `iris` 로 들어가 cut 만, 카메라 천천히, 효과음 없음.

## 제목 짓기 — YouTube API 로 키워드 확인

> 조사 · 해시태그 · 태그는 저장소 공용 스킬 **`yt-seo`** (루트에서 `npm run seo -- qna <편> "검색어" …`) 를 쓴다. 아래는 모답맨 제목 규칙.

1. 주제의 검색어 후보 8~12개(뉴스성 키워드 · "A B 차이" · "~뜻" · 생활형 질문)를 `npm run keywords -- "검색어" …` 로 조회한다 (키는 루트 `.env` 의 `YOUTUBE_API_KEY`, 검색어당 할당량 101).
2. **지금 뜨거운 말(최근 60일 영상이 많고 중앙값이 높은 것)을 제목 앞머리에**, 꾸준한 말("A·B·C 차이/정리")을 가운데, 끝에 `| 모답맨`.
3. 아이 질문형 훅을 살린다. 예: `검찰청 폐지되면 나쁜 사람은 누가 재판에 보내요? 경찰·검사·판사 3분 정리 | 모답맨`
4. 조회수 낮은 말은 제목 대신 태그로. 조사 표는 업로드 자료(`content/<편>/upload/upload.md`)에 남긴다.
5. 설명: 훅 2줄 → ✔ 오해 → 정답 4~5줄 → 챕터(`npm run motion-srt` 가 만든 시각, 각 10초 이상) → 모답맨 소개 한 줄 → ※ 주석 → 해시태그 5~6개.

## 영어 자막

- 한국어 한 줄에 영어 한 줄(`en`). 직역 말고 구어체, 90자 안. 한국에만 있는 말은 처음 한 번만 짧게 풀이.
- 민감한 소재에서 한국어가 말하지 않은 이유를 영어가 대신 설명하지 않는다.
- 영어 제목은 100자 안 (Studio 제한).

## 제작 순서 (자세한 명령은 `qna/CLAUDE.md`)

기획 `.md` → `script.json` → `art.json` · 그림(크롬 Gemini 또는 유료 artgen — 물어보고) → 음성(크롬 AI Studio 줄 단위 또는 유료 `voice gen` — 물어보고) → `npm run trim-voice` → `node scripts/voice.mjs epNN` → `node scripts/speed.mjs epNN` → 샷 계획 → Root `MOTIONS` 등록 → 스틸 몇 장으로 확인 → 렌더 → `npm run motion-srt -- epNN` → 썸네일 스틸 → 제목 조사 → Studio 업로드(비공개).
