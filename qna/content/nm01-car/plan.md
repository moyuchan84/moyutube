# 11화 · 내모남불 자동차편 — 기획 (초안 v1, 2026-10-25)

> funtube 「내로남불 · 운전석의 법칙」(일상 오류 신고센터)에서 다룬 끼어들기 · 깜빡이 · 주차를 모라구 모 씨네 가족으로 옮긴다.

## 1. 한 줄 컨셉

토요일, 모 씨네가 마트에 간다.
- 아빠는 남이 끼어들면 "칼치기!", 깜빡이 없이 오면 "불법!", 남이 소화전 앞에 대면 "신고!"를 외친다.
- 그런데 같은 짓을 자기가 할 때마다 "**모 어때~**" 하고 넘긴다.
- 그때마다 구석 카운터가 한 칸씩 오른다: "내모남불, 하나."
- 교통경찰관이 라운드마다 정색하고 바로잡는다.
- 모라구가 한 줄로 정리한다.

## 2. 모답맨과 무엇이 같고 무엇이 다른가

| | 모답맨 (1~10화) | 내모남불 자동차편 |
|---|---|---|
| 웃음의 축 | 아빠가 **모르고** 틀림 | 아빠가 **알면서** 자기만 봐줌 |
| 카운터 | "오답, N." + 正 | "**내모남불, N.**" + 正 (같은 장치, 말만 바꿈) |
| 아빠 자기소개 | "오답, 하나. 저는 모답맨입니다." | "내모남불, 하나. 저는… **모답맨**입니다." (시리즈 연결) |
| 정답 담당 | 편마다 제삼의 인물 | 교통경찰관 (세 라운드 모두 등장하는 반복 개그) |
| 라운드 | 개념 하나씩 | **ROUND 1 끼어들기 · ROUND 2 깜빡이 · ROUND 3 주차**. 라운드마다 "남이 하면 → 내가 하면 → 법은?" |
| 그대로 지키는 것 | | 부모-자녀 관계 · 집 밖 · 아이 눈높이 박자에 농담 없음 · 사실은 확인된 것만 · 마지막 반전은 아빠 · 3분 안쪽 |

**"불륜"이라는 말**
- 규칙상 민감한 단어는 제목 · 썸네일 · 화면 글자에 쓰지 않는다.
- 그래서 타이틀 카드는 "남이 하면 **불—**" 까지만 띄우고, 빨간 도장 **"법!"** 을 찍어 "불법"으로 만든다.
- 설명란에만 "내로남불의 모 씨네 버전"이라고 쓴다.

**내모남불 후보** (아빠의 이중 잣대):
1. 남이 줄 앞에서 끼면 "새치기!" ↔ 내가 끼면 "살짝 들어간 거야~"
2. 남이 깜빡이 없이 오면 "불법!" ↔ 나는 "마음속으로 켰어"
3. 남이 소화전 앞에 대면 "신고해!" ↔ 나는 "1분만, 모 어때~"
4. (반전) 이번엔 깜빡이를 켜긴 켰는데 2km 내내 안 끔 → 이건 내모남불이 아니라 그냥 **오답**
