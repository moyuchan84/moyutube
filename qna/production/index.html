우리 가족이 같이 만드는 법

질문 하나가 영상 한 편이 되기까지

Claude가 원고와 초안 영상을 만들면, 가족이 그림을 그리고 목소리를 입히고 움직임을 더해 완성합니다. 이 페이지 하나에 순서, 역할, 파일 규칙, 그리고 클립 스튜디오·애프터 이펙트·프리미어에서 꼭 알아야 할 것만 모았습니다.

1~5편 원고·콘티 완성 1편 초안 영상(가이드용) 완성 그림·녹음·움직임·편집 이제 시작
제작 순서 역할 나누기 파일 규칙 클립 스튜디오 애프터 이펙트 프리미어 애니메이트 4주 연습 올리기 전 점검

제작 순서

한 편은 일곱 단계를 거칩니다. 앞 단계의 결과물이 다음 단계의 재료라서, 순서를 건너뛰면 나중에 다시 하게 됩니다. 특히 2단계 초안 영상으로 길이를 먼저 정해 두면, 그림을 그렸다가 버리는 일이 없습니다.

처음 한 번 설정

새 캔버스
파일 → 신규 → 폭 3840, 높이 2160 픽셀, 해상도 150, 기본 표현색 컬러. 이걸 템플릿으로 저장해 두면 매번 설정하지 않아도 됩니다.
캐릭터 시트
아빠·엄마·아이를 각각 한 파일에 정면 기본, 당황, 땀 흘림, 깨달음, 뿌듯함 표정과 입 3장(닫힘/반/열림)으로 그려 둡니다. 채널 톤이 "당황하다가 명쾌하게 설명"이라서 표정 세트를 가장 많이 재사용합니다.
색 팔레트
캐릭터 피부·머리·옷 색을 컬러 세트에 저장해 둡니다. 편마다 색이 달라지는 것을 막아 줍니다.

한 컷을 그리는 순서

  1. 초안 컷 이미지를 참고 레이어로 깔기. video/out/ep06/cuts/03-c03.png를 캔버스에 끌어다 놓고 불투명도 30%. 구도와 인물 위치를 맞춥니다.다 그린 뒤 이 레이어는 지우거나 숨깁니다.
  2. 러프 → 선화. 러프는 아무 레이어에, 선화는 벡터 레이어에. 인물·소품·배경 선화를 각각 다른 레이어로.
  3. 캐릭터 시트에서 얼굴 가져오기. 표정 세트에서 필요한 얼굴과 입 3장을 복사해 붙이고 Ctrl+T로 크기를 맞춥니다.
  4. 채색. 선화를 참조 레이어로 두고 채우기. 인물별로 폴더를 만들어 정리.
  5. 레이어 이름 정리. 파일 규칙의 누구_부위_상태 규칙대로.
  6. 저장 두 번. c03.clip으로 저장하고, 파일 → 복제 저장 → art/c03.psd.

자주 막히는 곳

채우기를 했는데 빈틈으로 색이 새요

선이 완전히 닫혀 있지 않아서입니다. 채우기 도구 설정에서 "틈 닫기"를 켜거나, 새는 곳 선을 이어 주세요. 참조 레이어가 선화 레이어로 지정되어 있는지도 확인하세요.

PSD를 애프터 이펙트에서 열면 레이어가 하나로 합쳐져 있어요

"화상을 통합하여 내보내기"로 저장하면 합쳐집니다. 반드시 파일 → 복제 저장 → .psd로 저장하세요. 레이어 폴더와 벡터 레이어는 PSD로 저장할 때 래스터 레이어로 바뀌지만, 나뉘어 있는 것은 그대로 유지됩니다.

그리다 보니 어느 레이어에 그렸는지 모르겠어요

레이어 창에서 "편집 레이어 잠금"을 켜 두거나, 도구 속성의 "레이어 자동 선택"으로 그림을 클릭하면 그 레이어로 이동합니다. 처음부터 레이어를 만들고 이름부터 붙이는 습관이 가장 확실합니다.

애프터 이펙트

정지 그림에 움직임을 넣습니다. 우리가 쓰는 움직임은 다섯 가지뿐입니다. 천천히 확대, 튀어나오기, 흔들림(뚜둥), 입 뻐끔, 눈 깜빡. 이 다섯 개만 익히면 한 편을 만들 수 있습니다.

한 편을 만드는 순서

  1. 템플릿 복사. ae-template.aep를 ep06/ae/ep06.aep로 복사해서 엽니다. 첫 편이라면 새 프로젝트로 시작합니다.
  2. 컷마다 PSD 가져오기. Ctrl+I → c01.psd → "컴포지션 - 레이어 크기 유지". 컴포지션 이름이 c01이 되게 합니다. Ctrl+K로 1920×1080, 30fps로 맞추고, 그림 전체를 50%로 줄입니다(3840으로 그렸으니까).
  3. 녹음 넣기. 그 컷의 voice/c01-*.wav를 끌어 넣고, 초안 영상과 같은 위치에 놓습니다. 컷 길이는 초안 영상의 컷 길이에 맞춥니다.
  4. 천천히 확대. 컷 전체를 묶은 레이어(또는 널)의 크기를 처음 100% → 끝 105%. 초안 영상과 같은 느낌입니다.
  5. 입 뻐끔. 녹음 레이어를 선택하고 "오디오를 키프레임으로 변환" → "오디오 진폭" 레이어가 생깁니다. 입 3장 레이어의 불투명도에 각각 아래 식을 넣습니다. v = 뒤에는 소용돌이 아이콘을 오디오 진폭 레이어의 "두 채널 → 슬라이더"로 끌어서 채웁니다. 
    // 입_닫힘
v = (여기로 두 채널 슬라이더 끌어오기);
v < 4 ? 100 : 0

// 입_반
v = (여기로 두 채널 슬라이더 끌어오기);
(v >= 4 && v < 12) ? 100 : 0

// 입_열림
v = (여기로 두 채널 슬라이더 끌어오기);
v >= 12 ? 100 : 0
    4와 12는 출발점입니다. 입이 너무 자주 열리면 숫자를 올리고, 안 열리면 내리세요.
  6. 눈 깜빡. 눈_감음 레이어를 2~3초마다 3프레임씩만 보이게 합니다. 불투명도 키프레임 0 → 100 → 0, 또는 레이어를 잘라서 짧게 놓습니다.
  7. 뚜둥 흔들림. 뚜둥 효과음 위치에서 컷 전체 레이어의 위치 속성에 식을 넣고, 0.5초 뒤에 잘라냅니다. 
    wiggle(20, 15)   // 1초에 20번, 15픽셀만큼 흔들기
  8. 프리미어로 넘기기. 프로젝트를 저장하면 끝입니다. 프리미어에서 이 컴포지션을 바로 가져옵니다(다이나믹 링크). 따로 영상으로 뽑지 않아도 됩니다.

대부분 이름이 달라서입니다. 식 안의 레이어 이름을 직접 쓰지 말고, 소용돌이 아이콘으로 끌어서 연결하세요. 한글판과 영문판의 효과 이름이 달라도 끌어서 연결하면 맞게 들어갑니다.

한 편을 만드는 순서

  1. 초안 깔기. ep06.mp4로 시퀀스를 만들고, 초안은 맨 위 트랙(V3)에 둡니다. 불투명도를 30%로 낮추거나 눈 아이콘으로 껐다 켜며 비교합니다.초안의 컷 경계마다 M으로 마커를 찍어 두면 편합니다.
  2. AE 컷 바꿔 끼우기. ep06.aep를 가져와서 c01, c02… 컴포지션을 V1 트랙의 마커 위치에 놓습니다. 다 끼우면 초안 트랙을 끕니다.
  3. 소리 정리. 목소리 클립 전부 선택 → 기본 사운드 → 대화 → 음성 향상. 효과음을 넣고, 배경음악을 A3 트랙에 깔고 더킹을 겁니다.
  4. 자막. subtitles.srt를 가져오거나 텍스트 패널에서 새로 만들고, 원고와 대조해 틀린 글자를 고칩니다. 질문 카드·정리 카드는 템플릿으로.
  5. 가족 시사회 2차. 처음부터 끝까지 같이 봅니다. 고칠 곳에 M 마커를 찍고 마커 이름에 메모를 적습니다.
  6. 내보내기. Ctrl+M → 형식 H.264, 사전 설정 "고품질 1080p HD". 효과 항목에서 음량 정규화를 켜고 ITU BS.1770-3, 목표 −14 LUFS로 맞춥니다(유튜브 기준 음량).자막은 영상에 굽지 말고 .srt로 따로 내보내 유튜브에 올리는 쪽이 검색과 번역에 유리합니다. 캡션 트랙은 내보내기 → 캡션 → 사이드카 파일 만들기.

AE 컴포지션을 넣었더니 재생이 끊겨요

배경음악이 대사를 덮어요

미디어 오프라인이라고 빨간 화면이 떠요

파일을 옮기거나 이름을 바꿨을 때 생깁니다. 클립을 마우스 오른쪽 → 미디어 연결 → 파일 위치를 알려 주면 됩니다. 폴더 규칙을 지키면 거의 생기지 않습니다.

지금은 안 써도 됨

지금 우리 채널은 정지 그림에 가벼운 움직임을 얹는 형식이라, 애프터 이펙트 하나로 충분합니다. 툴이 하나 줄면 배울 것도 하나 줄어듭니다.

나중에 캐릭터가 걸어 다니고 손짓하며 말하는 장면이 많아지면 그때 애니메이트를 꺼내면 됩니다. 캐릭터를 "심볼"로 만들어 두면 편마다 재사용할 수 있고, 입 모양을 녹음에 자동으로 맞추는 립싱크 기능이 있습니다.

F8심볼로 변환

4주 연습 계획

툴을 다 배운 뒤에 시작하면 늦습니다. 이미 원고가 있는 1편 「호텔·모텔·유스호스텔」로 연습하면서 배우세요. 연습이 끝나면 1편이 완성되어 있습니다.

1주차

캐릭터 시트

  • 클립 스튜디오 기본 단축키 익히기
  • 아빠·엄마·아이 표정 5개씩
  • 입 3장, 눈 2장

목표: 캐릭터 시트 PSD 3개

2주차

1편 그림 + 녹음

  • 1편 컷 11장 그리기 (배경은 단순하게)
  • 1편 대사 녹음, 파일 이름 규칙대로
  • AE: PSD 가져오기와 키프레임

목표: art/ 와 voice/ 폴더 채우기

3주차

1편 움직임

  • 컷마다 천천히 확대 + 입 뻐끔
  • 뚜둥 흔들림, 눈 깜빡
  • 자막 상자 템플릿 하나 만들기

목표: ep01.aep 완성, 템플릿 저장

4주차

1편 완성 · 업로드

  • 프리미어로 조립, 음악, 자막
  • 가족 시사회 두 번
  • 점검표 확인 후 업로드

목표: 첫 영상 공개

두 번째 편부터는 캐릭터 시트와 템플릿을 재사용하므로 훨씬 빨라집니다. 막히는 곳이 생기면 Claude에게 화면을 설명하거나 캡처를 보여 주고 물어보세요.

올리기 전 점검

업로드 버튼을 누르기 전에 다 같이 한 번 확인합니다. 여기 체크한 표시는 이 기기에만 남습니다.
