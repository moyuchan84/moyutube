# 쇼츠 썸네일 가이드 — 세로 9:16 으로 만든다

모라구에서 **쇼츠로만 나가는 편**(모덕후 · 이게 모예요? · 내모남불 쇼츠 · 모답맨 쇼츠 …)은 썸네일을 **세로 1080×1920** 으로 만든다.
가로 썸네일(1280×720, `<id>-Thumb`)은 롱폼 본편에만 쓴다.

## 왜 (2026-11-01 확인)

모덕후 ①~④는 가로 썸네일(1280×720)을 쇼츠에 올렸다. 유튜브 채널의 **Shorts 탭 · 쇼츠 선반 · 검색의 쇼츠 칸은 썸네일을 세로 9:16 으로 보여 주면서 가로 그림의 가운데만 잘라 쓴다.**
1280×720 에서 가운데 405px 만 남아서, 왼쪽의 삼촌 얼굴은 잘리고 글자는 "예쁜 사…", "덜 지독…" 처럼 반쯤만 보였다.
같은 줄의 lab 과학 쇼츠는 세로 화면 그대로라 잘 보였다.

| 예전 (가로 썸네일이 잘린 모습, 180px) | 새 방식 (세로 썸네일, 180px) |
|---|---|
| 삼촌 없음 · 글자 반쪽 · 배경 방만 보임 | 배지 · 큰 글자 두 줄 · 도장 · 삼촌 얼굴이 다 보임 |

## 규칙

1. **크기는 1080×1920.** 가로 그림을 올리지 않는다. 롱폼 썸네일을 쇼츠에 재사용하지 않는다.
2. **실제로 보이는 크기는 가로 약 180px** (PC 채널 Shorts 탭 한 칸 · 폰 2열 그리드). 그래서
   - 글자는 **두 줄 + 도장 한 줄**까지. 한 줄은 **6자 안쪽**, 크기는 **150px 이상**(1080 기준). 도장 글자는 5자 안팎.
   - 문장을 다 쓰지 말고 질문의 핵심만: "예쁜 사람 / 방귀는 / [덜 지독?!]".
   - 작은 글씨(출처 · 오답 카운터 · 영어 줄)는 넣지 않는다. 안 읽힌다.
3. **주인공 하나 + 소품 하나.** 인물은 스티커(흰 테두리)로 화면 폭의 절반 이상, 얼굴이 크게. 장면 그림(방 · 화면 안 장면)을 액자로 넣지 않는다 — 작게 줄이면 무엇인지 안 보인다.
4. **안전 영역**
   - 위 0~200px: 시리즈 배지(`모덕후 ④ 방귀`)만. 배지는 자동으로 위 가운데에 붙는다.
   - 250~850px: **글자 영역** (큰 글자 두 줄 + 도장). 얼굴과 겹치지 않게 도장 아래에 머리가 오도록.
   - 850~1550px: 인물 얼굴 · 상반신 · 소품.
   - 1550px 아래(아래 20%): 조회수 · 제목이 덮는 자리 — 다리나 배경만. 글자 · 얼굴을 두지 않는다.
   - 양옆 60px 안쪽에 글자를 두지 않는다.
5. **배경은 밝고 단순하게**: `burst:` 방사형 두 색 + 집중선(`fx: lines`). 편마다 색 · 표정 · 소품을 바꿔 그림만으로 주제가 보이게 한다 (썸네일이 편마다 비슷하면 안 된다는 기존 규칙).
6. **민감한 단어는 쓰지 않는다** (몸 · 성 관련 소재는 화면 글자 · 썸네일에 안 쓴다 — qna/CLAUDE.md 고정 규칙).
7. 영상 첫 1초(훅 화면)도 썸네일처럼 읽혀야 한다 — 쇼츠 피드에서는 썸네일 대신 영상이 바로 재생된다.

## 만드는 법

`script/motion.json` 의 `thumb` 에 `vertical` 을 넣는다. 레이어 문법은 가로판 `thumb.layers` 와 같다 (좌표만 1080×1920 기준).
4편 예시 (`content/mk04-fart-beauty/script/motion.json`) — 새 편은 이걸 복사해서 글자 · 그림 · 색만 바꾼다:

```json
"thumb": {
  "badge": "모덕후 ④ 방귀",
  "layers": [ … 가로판 (롱폼이 없으면 생략해도 된다) … ],
  "vertical": {
    "layers": [
      { "bg": "burst:#FFEE58:#F9A825", "x": 540, "y": 1050 },
      { "fx": "lines", "x": 540, "y": 1100 },
      { "text": "예쁜 사람", "x": 540, "y": 345, "size": 170, "rot": -3 },
      { "text": "방귀는", "x": 540, "y": 520, "size": 170, "rot": -3 },
      { "img": "modeokhu/rose", "sticker": true, "x": 470, "y": 1310, "h": 860, "rot": -4 },
      { "img": "prop/rose-cloud", "sticker": true, "x": 830, "y": 1330, "h": 340, "rot": 12 },
      { "text": "덜 지독?!", "style": "stamp", "x": 540, "y": 715, "size": 165, "rot": -6 },
      { "fx": "kira", "x": 420, "y": 1000 }
    ]
  }
}
```

- `vertical.badge` 를 따로 주지 않으면 `thumb.badge` 를 쓴다.
- 레이어는 위에 적은 것이 아래에 깔린다. 도장은 인물 다음에 적어 맨 위로.

렌더 · 확인 (`qna/video` 에서):

```
npm run thumb-short -- mk05
```

- 결과: `content/<편>/upload/thumbnail-short.png` (1080×1920) 과 미리보기 `video/out/<편>/thumbnail-short-180.png` (가로 180px).
- **미리보기를 직접 열어 본다.** 180px 에서 큰 글자 두 줄 · 도장이 읽히고 얼굴이 보이면 통과. 안 읽히면 글자를 줄이고(자 수) 키운다.
- 컴포지션 id 는 `<motion id>-ThumbV` (예: `Mk04-Modeokhu-ThumbV`). Root 에 자동 등록된다.

## 업로드

- Studio 쇼츠 세부정보의 썸네일 칸에 `thumbnail-short.png` 를 넣는다 (가로 `thumbnail.png` 아님).
- 저장 뒤 채널 Shorts 탭(`youtube.com/channel/UCCIm8f5JE4b4PmSrPIJd7zQ/shorts`)에서 실제로 어떻게 보이는지 한 번 확인한다.
- 롱폼 + 쇼츠가 같이 나가는 편(내모남불 등): 롱폼은 가로 `thumbnail.png`, 쇼츠는 세로 `thumbnail-short.png`.
