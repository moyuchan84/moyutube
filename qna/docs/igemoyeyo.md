# 이게 모예요? — 모라구 시리즈 (기획)

> **"이게 뭐예요?" → "이게 모예요?"** 모라구가 낯선 물건 · 표시를 들고 묻는 쇼츠 전용 시리즈.
> 모라구 네 번째 카테고리. 기획 시작: 2026-10-29. 아직 만든 편 없음.

## 한 줄 컨셉

모라구가 길에서, 할머니 집 서랍에서, 옷 안쪽에서 처음 보는 것을 들고 "이게 모예요?" 하고 묻는다. 아빠가 자신 있게 엉뚱한 답을 하고, 정답과 **그게 왜 그렇게 생겼는지**를 보여 준다.

## 다른 카테고리와 무엇이 다른가

| | 모답맨 · 내모남불 · 포모라구 | **이게 모예요?** |
|---|---|---|
| 길이 | 3분 본편 + 쇼츠 3 | **쇼츠 전용 30~60초** |
| 한 편 | 주제 하나 · 라운드 셋 | **물건 · 표시 하나** |
| 만드는 양 | 편마다 크다 | 작아서 자주 올릴 수 있다 |

## 구조 (30~60초)

1. **물건 클로즈업** (0~3초) — 정체를 가린 채 일부만. 모라구 "이게 모예요?"
2. **아빠의 추측** (3~12초) — 자신만만한 오답 하나(상상 장면) → 카운터 "오답, 하나." (모답맨과 이어짐)
3. **정답 공개** (12~35초) — 전체 모습 + 이름 + 쓰던 법 / 뜻
4. **왜 이렇게 생겼나** (35~50초) — 이유 한 가지 (점자블록 모양, 저장 아이콘 등)
5. **마무리 한 줄** (50~60초) — 모라구의 한 줄 또는 아빠의 반전

## 소재 묶음

### A. 옛날 물건 (할머니 집 서랍에서)
- **플로피디스크** ⭐ — "저장 버튼이 이거였어?" 반전이 가장 강하다
- 카세트테이프와 연필 — 연필로 감는 이유
- 삐삐 — 숫자로 말하던 시절
- 공중전화 · 전화카드
- 필름 카메라 — 찍고 바로 못 보는 사진

### B. 길거리 표시
- **점자블록 두 종류** ⭐ — 줄무늬(가라) · 점(멈춰)
- 소화전
- 맨홀 뚜껑 무늬
- 전봇대 번호표 — 길을 잃었을 때 위치 알리기
- 도로 위 숫자 · 마름모 표시
- 지하철 노란 선

### C. 생활 기호
- 세탁 기호
- 분리배출 표시
- 유통기한 vs 소비기한 — 2023년부터 소비기한 표시로 바뀜
- 콘센트 접지
- 비상구 초록 사람 — 왜 초록색이고 왜 달리는가

⭐ = 먼저 만들기 좋은 것.

## 규칙

- 부모-자녀 관계, 집 밖(길 · 할머니 집 · 마트)에서.
- 사실은 확인된 것만. 법 · 제도(점자블록 규격, 소비기한 등)는 공식 자료로 확인하고 끝 화면에 짧은 주석.
- 상표 · 로고 없이 그린다. 실제 제품명 대신 일반 이름.
- 목소리는 고정 음색 그대로(아빠 · 나레이션 Algenib, 모라구 Leda, 엄마 Kore).
- 그림은 공통 그림(`content/_common/art`)을 최대한 재사용하고, 편마다 물건 그림 2~3장만 새로 만든다.

## 유튜브 (만들 때 정할 것)

- 재생목록 이름 후보: 「이게 모예요? · 모라구가 묻는 물건 사전」
- 제목 예: `저장 버튼이 이거였다고? 플로피디스크 | 이게 모예요?`
- 편 폴더 안: `qna/content/imNN-<slug>/` (unit.json 에 `"series": "igemoyeyo"`). 쇼츠 전용이라 `motion.json` 하나만 9:16 으로 둔다. 코드 연결은 1편을 만들 때 추가한다.
