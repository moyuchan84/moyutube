- 내레이션 음성(Gemini TTS)과 그림 생성은 모두 유료. **생성 전에 개수와 대략 비용을 알려 드리고 진행한다.**

## 만들 일 (순서)
1. 영어 대본 + 한국어 자막 → `script/narration.md` ✔(이번)
2. 사진 · 영상 후보 확인(`--dry`) → 받기 → 눈으로 고르기
3. Gemini 그림 프롬프트 목록 → 개수 · 비용 확인 → 생성
4. `Long.tsx` 에 새 장면: 데이터 도식 · 비교 · 타임라인
5. BGM `bgm/cheathistory.mjs`
6. 음성(승인 후) → 타이밍 → 렌더 → 스틸 점검
7. yt-seo → 업로드(확인 후)
