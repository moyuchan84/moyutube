# 새 채널 아이디어 메모 (2026-11-10)

> 모라구 분석을 하다 나온 생각을 그대로 남긴 문서. 결정이 아니라 메모다. 기획은 [new-channel-plan.md](new-channel-plan.md).

## 1. 나온 배경

- 모라구가 조회 · 구독이 안 늘어서 방향 전환이 필요한지 물었다 (분석은 [qna/docs/morago-growth.md](../qna/docs/morago-growth.md)).
- 핵심 숫자 (10-31 기준): 공개 104편 · 조회 41,711 · 구독 41. 조회가 1,000~1,300 에서 멈추고, 1천 회당 좋아요 5.5.
- **Gemini 그림 위주 제작은 공이 가장 많이 드는데 반응이 가장 낮았다.** 모답맨 3분 롱폼 중앙값 18 · 동화 6.5 · 모덕후 26 · 모 아니면 도 34 ↔ 코드로 그린 과학 쇼츠 1,182 · 아빠 오답 단독 쇼츠 1,195.
- 결론: Gemini 그림 중심의 3분 롱폼 · 동화 · 모 아니면 도 · 모덕후는 2주 쉬고, "지금 해 보세요" 과학 · 수학 쇼츠와 아빠 오답 단독 쇼츠에 집중한다 (사용자 확정 전, 제안 단계).

## 2. 사용자 아이디어 (원문 요지)

새 채널을 파서 아예 다른 방식으로 간다. 사람들이 좋아하는 소재:

- 세상에서 가장 무서운 곳 10위 같은 랭킹
- 연예인 가십 · 연예인 쇼츠
- 자극적인 것, 예쁜 것, 멍때리고 볼 것

주제 하나를 잡아 저작권 문제 없는 사진을 자동으로 모으고, 참신한 스타일로 편집해 자동으로 올리는 방법이 있는지.

## 3. 검토 결과

| 아이디어 | 판단 | 이유 |
| --- | --- | --- |
| 연예인 가십 · 연예인 쇼츠 | **하지 않는다** | 사진 · 영상은 저작권 · 초상권 · 퍼블리시티권. 사실 확인 없는 가십은 명예훼손. shortube 규칙(인물 사진 · 논란 · 사생활 금지)과도 충돌. 채널 정지 위험이 가장 크다. |
| 이미지 검색 크롤링 | **하지 않는다** | 검색된 사진은 대부분 저작권이 있다. 자동으로 긁어 올리면 신고가 쌓인다. |
| 완전 자동 대량 생산 | **그대로는 안 된다** | 같은 틀에 사진만 바꾸는 채널은 수익화에서 "진정성 없는 콘텐츠(대량 생산 · 반복)"로 거절될 수 있다. 편마다 사람의 판단이 들어가야 한다. |
| 세상에서 가장 ~한 곳 TOP N | **된다 (추천)** | 자극적이고 멍때리며 보기 좋다. 공공 도메인 사진과 지도로 만든다. |
| 우주 · 심해 · 극한 지구 | 된다 | NASA · NOAA 자료가 풍부하다. |
| 멍때리기용 영상 | 시험해 볼 만 | 만들기 쉽지만 쇼츠에서는 끝까지 보는 비율이 낮은 편. |
| "만약 ~하면?" 시나리오 | 된다 | 3D · 모션으로 직접 그리면 소스 문제가 없다. |

## 4. 저작권 문제 없는 재료

- **무료 이미지 · 영상 (상업적 사용 가능, API 있음):** Pexels · Pixabay · Unsplash
- **공공 도메인 · 자유 이용:** Wikimedia Commons(라이선스별로 CC0 · CC-BY 구분, 출처 표시), NASA · NOAA · 스미소니언
- **직접 만든 것:** AI 이미지 · 영상, 코드로 그린 그래픽 · 지도 (Natural Earth 지도는 퍼블릭 도메인)
- **음악:** 코드 합성 BGM (Content ID 걱정 없음)
- 받을 때마다 출처 · 라이선스 · 받은 날짜를 기록한다.

## 5. 주의

- `shortube/CLAUDE.md` 의 "사진 · 영상 클립은 쓰지 않는다"는 **숫자로 보는 요즘 채널 전용 규칙**이다. 새 채널은 별도 프로젝트로 두고 규칙도 따로 쓴다. shortube 규칙을 바꾸지 않는다.
- 새 채널은 구독자 0 에서 다시 시작한다. 20~30편 시험 뒤에 계속할지 판단한다.
- 같은 계정으로 다른 채널을 돌려 올리는 식의 우회는 하지 않는다.
