그림 · 음성 스타일 가이드

채널마다 AI 그림의 화풍 문장, AI Studio 에서 고르는 목소리, 말투 지시(Style)를 그대로 옮겨 적었습니다. 새 편을 만들 때 여기서 복사해 쓰면 편이 바뀌어도 그림체와 음색이 흔들리지 않습니다.

0. 공통

무엇어디서메모
음성Google AI Studio — Generate speech사전 정의 목소리(Algenib · Leda …) 중에서 고르고, Style 칸에 말투를 영어 문장으로 적는다. 받은 파일은 24kHz · 16비트 · 모노 WAV.
그림Gemini 앱(손으로) 또는 Gemini API(스크립트)캐릭터 · 소품은 단색 초록 #00FF00 배경으로 받아서 코드가 배경을 지운다.
API 키저장소 루트 D:\youtube\.env 하나만GEMINI_API_KEY(기본) · GEMINI_API_KEY2(한도에 걸리면 예비). 프로젝트마다 복사하지 않는다.
그림 · 음성 API 는 돈이 든다. 사용자가 "API 로 만들어 줘"라고 할 때만 실행한다. 점검만 할 때는 무료 모드(artgen.mjs epNN --list, voice.mjs epNN jobs / studio, facegen.mjs --list)를 쓴다.

세 채널이 똑같이 지키는 것

  • 목소리 복제 기능은 쓰지 않는다. 실존 인물 목소리를 흉내 내지 않고, 사전 정의 목소리만 쓴다.
  • 그림에 글자를 그리지 않는다. 자막 · 간판 · 숫자는 영상 코드가 얹는다. 모든 프롬프트 끝에 No text, no letters, no numbers, no logos.
  • 정해진 목소리는 바꾸지 않는다. 바꿔야 하면 설정 파일과 이 문서를 같이 고치고 날짜를 남긴다.
  • 말투 지시는 Style 칸(또는 API 프롬프트 앞머리)에만 쓴다. 대사 칸에 쓰면 그대로 읽어 버린다.

AI Studio 에서 손으로 만드는 순서

  1. qna/video 에서 npm run voice -- epNN studio → out/epNN/voice-studio.html 을 연다. 컷마다 대사 복사 버튼과 그 컷에서 고를 목소리가 적혀 있다.
  2. AI Studio 를 여러 화자(Multi-speaker) 모드로 두고 Speaker 1 = Algenib, Speaker 2 = Leda.
  3. 화면이 블록 방식이면 아빠 · 나레이션 블록의 Style 칸에 Speaker 1 말투 지시를 넣는다.
  4. 손님 · 엄마가 나오는 컷은 그 컷에서 비는 자리를 바꾼다. 예: 아빠 + 할머니 → Speaker 2 = Gacrux / 아이 + 엄마 → Speaker 1 = Kore.
  5. 생성 → voice-studio/epNN/<컷id>.wav 로 저장 → npm run voice -- epNN split 으로 줄마다 자르고 타이밍 갱신.
한 컷에 목소리는 둘까지. AI Studio 가 두 자리뿐이라 아빠 · 아이 · 엄마가 한 컷에서 모두 말하면 오류가 난다. 대본에서 컷을 나눈다 (npm run voice -- epNN jobs 가 검사).

고른 과정: 아빠 Fola → Varo → Algenib("좀 더 굵게"), 아이 Rami → Leda("좀 더 어리게"). 안 써 본 후보: 아빠 Ludo · Bodi, 아이 Zephyr · Laomedeia · Achernar.

1-2. 그림 — 화풍

모든 그림 프롬프트는 이 화풍 문장으로 시작합니다 (prompts.mjs 의 STYLE):

Japanese gag-manga sticker illustration style. Grotesquely exaggerated comedic expressions, huge open mouths with detailed teeth and gums, bulging eyes, sweat drops, wrinkles. Semi-realistic airbrushed skin shading with glossy highlights. Big head, short stocky body (about 2.5 heads tall). Thin brown-black ink linework, saturated colors, clean edges. Korean setting, Korean people unless stated otherwise. No text, no letters, no numbers, no logos, no watermark, no signature.

shortube2. 숫자로 보는 요즘

2-1. 그림 — 쓰지 않는다

화면은 1080×1920 에 글자 · 도형 · 코드로 직접 그린 차트만 씁니다. AI 그림, 사진, 로고, 캡처, 앨범아트는 쓰지 않습니다 (COMPLIANCE_GUIDE 1-1). 대신 쓰는 재료:

  • 코드 생성: SVG 필터(아지랑이 feTurbulence, 노이즈), 입자(낙엽 · 비), 그라디언트, 도형 패턴, 카메라 팬 · 줌
  • 라이선스가 분명한 외부 자료: Natural Earth 지도, Material Symbols · Tabler Icons, Noto Emoji, OFL 폰트 — video/public/<종류>/LICENSE.md 에 출처를 적는다
  • 브랜드: 남색 바탕 + 노랑 선 + 분홍 점 (video/src/Brand.tsx). 첫 1초 로고 띠나 마지막 띠로만 지키고, 본문 색은 주제에 맞춰 바꾼다.

2-2. 음성 — 지금은 없음, 넣을 때의 기준

올린 9편은 모두 음성 없이 자막 + 코드 합성 배경음악입니다. 그래서 업로드 때 AI 사용 = "아니요"로 둡니다. 내레이션을 넣기 시작하면 설명란에 내레이션에 AI 음성을 사용했습니다 한 줄을 넣습니다. 아래는 shortube/TTS_GUIDE.md 의 기준이며, 목소리는 아직 확정 전입니다.

목소리 정체성: "데이터 좋아하는 친한 친구" — 뉴스 앵커도, 흥분한 예능 자막도 아닌 중간. 영상마다 목소리를 바꾸지 않고 하나로 고정, 카테고리별로는 Style 만 바꿉니다.

3-1. 목소리 — 한 줄씩 단일 화자

funtube 는 대사 한 줄마다 따로 생성합니다(node scripts/tts.mjs). AI Studio 에서 손으로 할 때는 단일 화자(Single-speaker) 모드로 두고, 아래 표의 목소리를 고른 뒤 Style 칸에 그 줄의 style 을 넣습니다.

스크립트가 API 에 보내는 문장 모양 — AI Studio 에서도 같은 효과를 내려면 Style 칸에 톤을, 대사 칸에는 대사만:

Speak in Korean. Tone: {style}. Say only this line:
{대사 — 화면 글자와 다르게 읽혀야 하면 say 값}
  • 화면 글자와 읽는 말이 다르면 say 에 적는다. 예: 화면 ㅋㅋㅋㅋ → 읽기 푸하하하하하, 화면 ? → 읽기 ...뭐?.
  • 선배 = Charon, 후배 = Puck 은 3D 콩트 시리즈의 고정 짝이다. 새 직장 콩트도 같은 조합으로.
  • 모델 기본값은 gemini-2.5-flash-preview-tts (환경변수 GEMINI_TTS_MODEL 로 바꿀 수 있음). 키가 없으면 음성 없이 글자 수로 길이만 추정한다.
  • 노래 「길이 막혔어」(ride)는 음성 없음 — 비트만 npm run beat 로 코드 합성하고 가사는 화면 글자로.
채널 간 겹침 주의: funtube 엄마 Kore · 아이 Leda 는 qna 의 엄마 · 아이와 같은 목소리이고, Charon 은 qna 이발사 할아버지와 같습니다. 같은 사람이 보는 채널이면 "같은 가족"처럼 들릴 수 있으니, 새 인물을 만들 때는 겹치지 않는 목소리(예: Despina · Callirrhoe · Sadaltager)를 먼저 들어 봅니다.

3-2. 그림 — 얼굴 표정 6칸 시트

몸 · 무대는 코드(3D), 얼굴만 AI 가 그립니다. 인물마다 표정 6개를 한 장(3×2, 3:2 가로)에 받아 node scripts/facegen.mjs 가 초록을 지우고 public/faces/<이름>_1..6.png 로 자릅니다. 프롬프트만 보려면 --list(무료).

화풍 (faces.json 의 style):

Korean webtoon gag-comic style, 'grotesque-cute': deadpan, slightly unsettling and funny and adorable all at once. Thin, slightly wobbly hand-inked black outlines, completely flat colors with no shading or gradients, slightly asymmetrical naive hand-drawn features, huge round glossy eyes with tiny pupils, minimal nose, a small very expressive mouth, and exaggerated expressions that tip back and forth between cute and creepy. Imperfect scribbly charm, like a gag webtoon.

할 일 — 얼굴 윤곽 · 머리카락 없이 이목구비만 (3D 머리에 붙이기 때문):

Draw a reference sheet of 6 FACE DECALS of the SAME character, to be projected onto a smooth blank 3D head. Draw ONLY the facial features: eyes, eyebrows, nose, mouth, cheek blush, and small comic marks (sweat drops, anger veins, sparkles) right next to the face. DO NOT draw any head outline, face shape, skin color fill, hair, ears, neck, or body: the features float alone on the background.
번호표정지시
1무표정NEUTRAL: deadpan, half-lidded eyes, tiny straight closed mouth.
2말함TALKING: mouth open mid-sentence as a wide rounded shape with a hint of teeth, eyebrows slightly raised.
3화남ANGRY: brows slammed down hard, gritted teeth, one throbbing anger-vein mark beside the eye.
4충격SHOCK: eyes gigantic with tiny pinpoint pupils, mouth gaping open, one big sweat drop, brows very high.
5귀여움CUTE: sweet closed-eye or sparkling-eye smile, rosy blush circles on both cheeks, adorable.
6섬뜩UNCANNY: an unnervingly wide fixed grin stretching almost from cheek to cheek, huge round unblinking eyes with pupils far too small, slightly asymmetrical, eerie but hilarious.

대본의 "face": {"선배": 3} 이 이 번호입니다 (3 = 화남).

인물설정 문장
선배CHARACTER: a smug, middle-aged Korean office senior. Round thin-rimmed glasses drawn as part of the face (draw the glasses in every expression), heavy sleepy eyelids, bags under the eyes, a thin self-satisfied mouth, thick bushy eyebrows.
후배CHARACTER: a young, tired but earnest Korean junior office worker. Big round eyes, thick short eyebrows, faint dark circles under the eyes, a small mouth, no glasses.

배치 지시 — 칸이 겹치면 자르기가 실패하니 그대로 씁니다:

Layout: a grid of exactly 3 columns by 2 rows on a SOLID PURE GREEN (#00FF00) background, landscape 3:2 image. Each expression sits alone in its own cell, centered, with very wide empty green margins around it and between cells (at least 15% of the cell width) so nothing ever touches or overlaps another cell. All six faces must use exactly the same scale, the same eye-line height and the same eye spacing so they line up on the same head. Faces look straight at the viewer. Use only black ink lines, white eyeballs with black pupils, pink blush, and warm accent colors; NEVER use green anywhere in the drawing. No text, no numbers, no labels, no arrows, no frames, no borders.
  • Gemini 앱에서 손으로 뽑을 때: 위 다섯 덩어리(화풍 → 할 일 → 인물 → "The 6 expressions, in reading order:" + 표정 6줄 → 배치)를 이 순서로 붙여 한 번에 보낸다. 받은 그림은 funtube/art/faces/raw_<이름>.png 로 저장하고 node scripts/facegen.mjs <이름> --process-only.
