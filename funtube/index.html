만드는 법

funtube 폴더에서

📝 대본 쓰기

content/episodes.json 에 한 편을 추가. 줄마다 누가 · 무슨 말 · 어떤 말투(style)와 카메라 · 표정 · 효과음을 적는다.

🎙️ 음성

node scripts/tts.mjs — Gemini 음성으로 줄마다 녹음. 키는 저장소 루트 .env 하나만 쓰고, 돈이 드니 요청할 때만.

😀 표정 그림

scripts/facegen.mjs 로 인물마다 표정 6장 시트를 뽑아 public/faces/ 에. 3D 몸에 얼굴만 붙인다.

🥁 음악 · 효과음

npm run beat 로 노래 비트를 코드 합성. 문 · 경적 · 펀치 같은 효과음은 public/sfx/ 에.

🎬 미리보기 · 렌더

npm run studio 로 보면서 고치고, npm run render 로 1080×1920 영상. 결과는 out/ (저장소에 안 올림).
