# 그림톤 가이드

한 줄로: **굵고 거친 먹선의 흑백 웹툰 — 검은 덩어리로 명암을 치고, 마음이 닿는 사물 하나에만 색이 있다.**
(흑백 + 임팩트 컬러라는 방식만 참고한다. 특정 작품의 인물 · 구도 · 컷을 따라 그리지 않는다.)

## 1. 선 · 명암

| 항목 | 규칙 |
|---|---|
| 외곽선 | 붓펜 느낌의 굵기 변화가 큰 선. 인물 외곽 굵게, 안쪽 주름은 가늘게. |
| 명암 | 회색 그라데이션보다 **순흑 덩어리(먹)** 로 그림자를 친다. 얼굴 반을 검게 먹이는 컷을 아끼지 않는다. |
| 중간 톤 | 망점 스크린톤(점 크기 2단계)만. 매끈한 에어브러시 금지. |
| 질감 | 종이 질감 + 약간의 잉크 번짐. 과거(해진)는 거칠게, 현재(서울)는 선이 정돈되고 여백이 많다. |
| 배경 | 사진 같은 정밀 배경 X. 크레인 · 전깃줄 · 방파제 같은 **실루엣 + 해칭**. 감정 컷은 배경을 지우고 흰 여백이나 검은 바탕. |
| 효과 | 집중선 · 속도선 · 먹 튀김(타격) · 빗줄기 직선. 효과도 흑백. |

## 2. 색 — 쓸 수 있는 값은 이것뿐

| 이름 | 값 | 쓰는 곳 (SERIES.md 3절 규칙) |
|---|---|---|
| 먹 | `#111111` | 선 · 그림자 |
| 종이 | `#F4F1EA` | 흰 바탕 (순백 대신 살짝 누런 종이색) |
| 회색 톤 | `#8A8A8A` · `#C9C6BF` | 스크린톤 두 단계 |
| 하린의 빨강 | `#E0362B` | 무결 시점의 하린 물건 |
| 무결의 파랑 | `#2F6FD6` | 하린 시점의 무결 물건 |
| 동수의 노랑 | `#F2C230` | 2부 8화의 한 컷 |
| 바랜 빨강 | `#B58A86` → `#9A9A9A` | 무결이 포기할 때 채도가 빠지는 중간값 |
| 네거 | 반전 (먹↔종이) | 폭력 결정 컷 |

- 색은 **평평하게** 칠한다 (그라데이션 · 하이라이트 없음). 흑백 위에 색종이를 오려 붙인 느낌.
- 색 면적은 화면의 **5% 안** — 그래서 눈이 간다. 예외: 20화 풀컬러.
- 풀컬러(20화)는 수채 느낌의 번짐으로 사물 → 배경 순서로 퍼진다. 이때만 색 그라데이션 허용.

## 3. 캐릭터 고정 (모델 시트)

모든 인물은 `comics/art/ref/` 에 **기준 그림 세트**를 먼저 만들고, 이후 모든 컷 생성에 첨부한다 (qna 의 기준 그림 첨부 방식과 같다).

| 인물 | 기준 그림 | 실루엣 포인트 (멀리서도 알아보게) |
|---|---|---|
| 차무결 (19) | 정면 · 옆 · 뒷모습 · 손(붕대) 클로즈업 · 표정 6종 | 열린 교복 재킷, 붕대 감은 두 손, 짙은 일자 눈썹 (얼굴 흉터 없음) |
| 차무결 (25) | 정면 · 작업복 · 표정 4종 | 짧은 머리 유지, 장갑 아래 붕대, 어깨가 넓어짐 |
| 서하린 (19) | 정면 · 옆 · 카메라 든 포즈 · 표정 6종 | 단발 + 핀, 목도리, 목에 건 필름 카메라 |
| 서하린 (25) | 정면 · 스튜디오 복장 · 표정 4종 | 머리를 묶음, 카메라는 디지털+필름 두 대 |
| 구동수 | 정면 · 먹는 포즈 · 표정 6종 (과장 가능) | 까치머리, 큰 뿔테 |
| 백기현 | 정면 · 차 창문 너머 · 웃는 눈 클로즈업 | 셔츠 소매 걷음, 가는 손가락, 박하사탕 |
| 봉순 할머니 · 은결 · 할머니 | 정면 · 대표 포즈 | 국자 / 장난감 카메라 / 뜨개질 |

- **표정 6종:** 무표정 · 작은 웃음 · 놀람 · 분노(먹 그림자) · 울음 참기 · 당황.
- 무결은 웃는 얼굴을 시즌 중 **세 번만** 그린다 (3화 할머니, 7화 등대, 20화). 귀할수록 힘이 있다.
- 비율: 등신은 7.5–8 (현실적 청춘물). 동수만 표정이 데포르메될 수 있다(개그 컷 한정).

## 4. 시점별 · 시간대별 톤 차이

| 구분 | 화면 |
|---|---|
| 과거 · 무결 시점 | 거칠고 먹이 많다. 하린 물건만 🔴. |
| 과거 · 하린 시점 | 필름 사진처럼 입자(grain) + 프레임 가장자리 약간 어둡게. 무결 물건만 🔵. |
| 과거 · 동수 시점 | 선이 둥글고 가볍다 (개그 톤). 8화 한 컷만 🟡. |
| 현재 (서울) | 선이 깔끔하고 여백이 많다. 회색 톤 비중 ↑, 먹 덩어리 ↓. 색 없음. |
| 폭력 | 네거 + 먹 튀김 + 화면 기울임(더치 앵글). |
| 회상 속 회상 | 테두리를 찢어진 종이처럼. |

## 5. 그림 만드는 법 (Gemini · 돈이 든다 — 요청할 때만)

1. **흑백으로만 생성한다.** 색이 들어갈 사물도 흑백으로 그린다. 프롬프트에 색 지시를 넣지 않는다 → 그림체가 흔들리지 않는다.
2. **색은 후처리 레이어로.** 색이 들어갈 사물만 따로 마스크 PNG(`cNN.mask-red.png` 등)를 만들어 Remotion 에서 얹는다. 그래야 '색이 번지는' · '바래는' 연출을 코드로 움직일 수 있다.
3. **세로로 길게 생성한다.** 화면은 1080×1920 이지만 카메라가 웹툰처럼 아래로 내려가거나 패닝하도록 컷 그림은 **1080×2400 이상** 또는 가로 여유 있게.
4. **기준 그림 첨부:** 등장인물의 ref 를 매번 붙인다. 앞 컷과 이어지는 장면이면 앞 컷도 붙인다.
5. **확인:** 생성 후 손 모양(붕대) · 소품(목도리 · 카메라) · 얼굴 흉터가 생기지 않았는지 컷마다 검사. 틀리면 그 컷만 다시.

### 프롬프트 틀 (영어, 흑백 고정 부분은 매번 그대로)

```
STYLE (fixed): Korean webtoon panel, black-and-white ink only, bold brush-pen outlines with strong line weight variation,
solid black ink shadows, halftone screentone (two dot sizes), off-white paper texture, slight ink bleed, no color, no gray gradients,
cinematic composition, vertical 9:16 framing with extra headroom.
CHARACTERS: <ref 이름 · 고정 특징 한 줄씩>
SHOT: <샷 크기 · 앵글 · 렌즈 느낌>
SCENE: <장소 · 시간 · 날씨 · 행동 · 표정>
NO: text, speech bubbles, logos, real brand names, color.
```

- 말풍선 · 효과음 글자는 **그림에 넣지 않는다.** 전부 Remotion 에서 얹는다 (번역 자막 · 수정이 쉽다).

## 6. 파일 규칙

```
comics/
  art/ref/<인물>-<나이>-<포즈>.png      기준 그림
  art/epNN/cNN.png                      컷 원본 (흑백)
  art/epNN/cNN.mask-<red|blue|yellow>.png  색 사물 마스크
  storyboard/epNN.md                    콘티
```

- 자동 생성 그림을 저장소에 올릴지는 qna 와 같은 규칙을 따른다 (생성물은 커밋하지 않는 쪽이 기본 — 정해지면 `.gitignore` 에 추가).
