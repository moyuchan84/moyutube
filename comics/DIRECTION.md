# 연출 가이드

목표: **정지된 만화가 아니라 '읽히는 영화'.** 그림은 1–2초마다 무언가 움직이고(morago-growth 6절), 결정적인 순간에만 진짜로 움직인다.

## 1. 영상 포맷

| 항목 | 값 |
|---|---|
| 화면 | 1080×1920 (9:16), 30fps — 웹툰의 세로 스크롤과 쇼츠 피드를 그대로 쓴다 |
| 한 화 길이 | 2–3분 (쇼츠 최대 3분 안). 첫 화는 2분 30초 안 권장 |
| 몰아보기 | 부마다 5화 묶음 세로 영상 (10–13분) |
| 엔진 | Remotion (루트 CLAUDE.md). 컷 = 그림 + 색 마스크 + 말풍선 + 효과음 레이어 |
| 소리 | 목소리 없음(기본) — 말풍선 + 효과음 + 음악. 반응을 본 뒤 성우 TTS 를 검토 |

## 2. 한 화의 리듬 (2분 30초 기준)

| 구간 | 길이 | 내용 |
|---|---|---|
| 0:00–0:03 | 3초 | **현재 오프닝 1컷** + 내레이션 박스 한 줄. 첫 1초에 상황(누가 · 어디 · 무엇)이 보여야 한다 |
| 0:03–0:06 | 3초 | 타이틀 — 흑백 제목 글자 위로 그 화의 색이 한 방울 번짐 |
| 0:06–2:10 | ~2분 | 과거 본편 (4–6 장면, 25–40컷) |
| 2:10–2:20 | 10초 | 클리프행어 컷 — 정지 + 소리 하나 |
| 2:20–2:30 | 10초 | 끝 카드 (5절) |

- 컷당 평균 **2–4초.** 4초 넘게 머무는 컷은 반드시 카메라나 요소가 움직인다.
- 장면 사이엔 **숨 쉬는 컷**(바다 · 크레인 · 하늘 실루엣, 1.5초)을 하나씩 둔다.

## 3. 컷 연출 문법

### 3-1. 칸 열기 (웹툰 → 영상)
- **세로 스크롤(틸트 다운):** 긴 세로 그림을 위에서 아래로 훑는다 = 웹툰을 내리는 느낌. 시선이 위→아래로 떨어지는 장면(옥상에서 아래 골목, 비 내리는 하늘 → 우산)에 쓴다.
- **칸 분할 등장:** 한 화면에 2–3칸이 순서대로 미끄러져 들어온다. 대화 주고받기 · 동시에 일어나는 일(12화 5분 차이)에.
- **칸 깨기:** 인물이 칸 테두리를 뚫고 나온다. 액션 · 감정 폭발 컷 한정.
- **여백 컷:** 칸 없이 흰 종이 위에 인물 하나. 고백 직전 · 이별 같은 정적에.

### 3-2. 카메라 (정지 그림을 움직이는 법)
- **켄 번즈:** 느린 줌인(클로즈업 감정) / 줌아웃(고립감, 크레인 아래 작은 무결).
- **패럴랙스:** 그림을 앞 · 중간 · 뒤 레이어로 나눠 다르게 움직인다 (전경 전깃줄 · 인물 · 하늘). 장면 첫 컷에 주로.
- **흔들림:** 타격 · 고함에 2–4프레임만. 계속 흔들지 않는다.
- **더치 앵글:** 화면 기울임 5–10°. 기현이 나오는 컷 · 폭력 컷 전용.

### 3-3. 부분 움직임 (리미티드 애니메이션)
- 눈 깜빡임 · 머리카락 · 목도리 끝 · 빗줄기 · 담배 대신 박하사탕 굴리기 · 파도 · 필름 감는 손.
- 생성: 같은 컷을 레이어로 나누거나, 2–3장의 차이 그림을 번갈아 (12fps 느낌으로 끊어서).
- 입모양은 움직이지 않는다 (목소리가 없으니까).

### 3-4. 진짜 움직이는 장면 (사쿠가 컷)
- **한 화 1–2번, 2초 안.** 그 화의 결정적 순간만 (1화 단 한 방 · 6화 우산 던지기 · 14화 첫 주먹 · 20화 셔터).
- 6–12장의 연속 그림을 12fps 로. 움직임 직전 0.3초 정지(타메) → 움직임 → 정지 + 효과음.
- 사쿠가 컷 바로 뒤엔 반드시 조용한 컷을 둔다 (대비가 힘이다).

## 4. 전환 (컷씬)

| 전환 | 모양 | 쓰는 때 |
|---|---|---|
| **색 번짐** | 그 사물에서 색이 잉크처럼 번지며 다음 컷으로 | 색이 처음 나올 때 · 시점이 바뀔 때 (시리즈 대표 연출) |
| **색 바램** | 색이 채도가 빠지며 회색으로 → 다음 컷 | 포기 · 이별 (8화 · 15화) |
| **네거 플래시** | 2–3프레임 흑백 반전 | 타격 · 폭력 장면 진입 |
| **셔터** | 위아래 검은 막이 닫혔다 열림 + 찰칵 | 하린 시점으로 들어가거나 나올 때 |
| **필름 번(burn)** | 화면 가장자리가 하얗게 타며 | 과거 → 현재 (화 첫 컷 ↔ 본편) |
| **잉크 와이프** | 먹물이 쓸고 지나감 | 장면 · 장소 바뀜 (기본 전환) |
| **찢어진 종이** | 화면이 찢어지며 회상 | 회상 속 회상 |
| **암전** | 검은 화면 + 흰 글자 | 부의 끝 ("그리고, 여섯 해.") |

- 페이드 · 디졸브 같은 영상 기본 전환은 쓰지 않는다. 모든 전환은 **잉크 · 종이 · 필름** 재료로.

## 5. 끝 카드 (morago-growth 1절)

- 클리프행어 컷 위에 그대로 얹는다 (따로 구독 장면 만들지 않는다).
- **댓글 질문 하나:** 그 화의 선택지를 묻는다. 예) 1화 "하린이는 왜 필름을 안 줬을까?" / 8화 "무결이는 물러서는 게 맞았을까?"
- **구독 한 줄 (이유 붙여서):** "○화에서 둘의 색이 처음 겹칩니다 — 이어 보려면 구독" 처럼 다음 화를 볼 이유.
- "N화 →" 화살표 + 재생목록 「색이 번지는 날 시즌 1」.
- 거짓 약속(두 번 누르면 공개 등) 금지.

## 6. 소리

| 소리 | 규칙 |
|---|---|
| 음악 | 피아노 · 어쿠스틱 기타 중심의 잔잔한 테마 하나 + 긴장 테마(저음 현 · 심장 박동) + 액션 테마(드럼). 실제 노래 쓰지 않음, 코드 합성 또는 직접 만든 곡 (bgm-per-episode 원칙). |
| 테마 짝 | 무결 = 낮은 첼로 음 하나, 하린 = 셔터 소리 + 높은 피아노 음. 색이 처음 나올 때 그 사람의 음이 울린다. |
| 효과음 | 셔터 찰칵 · 박하사탕 딱 · 파도 · 갈매기 · 빗소리 · 붕대 감는 소리 · 타격. |
| 침묵 | 클리프행어 직전 0.5초 모든 소리 끔. 사쿠가 직전 타메에도 무음. |
| 공간음 | 해진 장면은 항상 바람 · 파도 바닥 소리가 깔린다. 서울은 차 소리 · 지하철 · 형광등 웅웅. |

## 7. 제목 · 썸네일 · 업로드

- **제목 틀:** `<훅 한 줄> | 색이 번지는 날 N화` (훅은 그 화의 대사나 상황, 40자 안). 올리기 전 반드시 `yt-seo` 로 검색어 조사 (웹툰 · 로맨스 · 학원물 · 애니 키워드).
- **썸네일:** 세로 1080×1920 (`shorts-thumbnail-vertical` 규칙). 흑백 인물 클로즈업 + 그 화의 색 사물 하나 + 짧은 글자.
- **재생목록:** 「색이 번지는 날 시즌 1」. 화 순서대로.
- **올리는 간격:** 일주일에 2–3화, 요일 고정 (연재는 기다림이 상품이다). 한 번에 몰아 올리지 않는다.
- **시험 연재:** 1부 5화를 모라구에 올린 뒤 `조회수 대비 구독` · `다음 화 이동률` 을 다른 시리즈와 비교해 새 채널 독립 여부를 정한다.

## 8. 화면 위 글자 위치 (9:16 안전 영역)

- 위 250px · 아래 400px 는 유튜브 UI 가 덮는다 → 말풍선 · 내레이션 박스는 그 사이에.
- 오른쪽 120px (좋아요 · 댓글 버튼) 에 중요한 얼굴 · 풍선을 두지 않는다.
