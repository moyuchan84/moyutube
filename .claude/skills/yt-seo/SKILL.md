# yt-seo — 노출되는 제목 · 해시태그 정하기

업로드 직전에 **매번** 한다. 제목은 감으로 짓지 않고 YouTube API 조사 표로 정한다. 조사는 무료(할당량만 쓴다 — 검색어 하나에 약 101, 하루 10,000).

## 1. 검색어 후보 8~12개 고르기

- **주제 말:** 시청자가 검색창에 칠 말 (예: 층간소음, 주차 두 칸, 택배 상자 분리수거)
- **뉴스성 · 유행어:** 지금 이야기되는 말 (예: 벼락거지, 직장인 공감)
- **시리즈 말:** 내모남불 → "내로남불", "○○ 내로남불" / 모답맨 → "○○ 차이", "○○ 뜻"
- **질문형:** 아이 질문 그대로 (예: "층간소음 기준", "닫힘 버튼 소용")
- 한 단어 말과 두세 단어 말을 섞는다.

## 2. 조사 돌리기 (저장소 루트에서)

```
npm run seo -- <project> <code> "검색어1" "검색어2" …
```

- 검색어마다: 조회수 중앙값 · 최근 60일 영상 수 · 1~5위 제목 · 상위 영상의 태그 · 해시태그 · **자동완성(연관 검색어)**.
- 편을 주면 `<편>/upload/upload.md` 맨 위 `<!-- seo:start --> … <!-- seo:end -->` 칸을 새로 쓴다 (그 칸은 손으로 고치지 않는다).
- 자동완성에서 더 좋은 말이 나오면 그 말로 한 번 더 돌린다 (최대 두 번).
- 편 없이 화면에만: `npm run seo -- "검색어" …`
- 안 올린 편 중 조사 · 제목이 빠진 것: `npm run seo-check`

## 3. 제목 정하기 — 표의 "쓰는 곳" 대로

- **🔥 제목 앞 (지금 뜨거운 말)** 을 맨 앞에. 없으면 중앙값이 가장 큰 "제목" 말.
- 뒤에 훅: 이중 잣대 · 아이 질문 · 숫자 없이 반전 ("남이 하면 ○○, 내가 하면?").
- 끝에 시리즈 꼬리표. 시리즈 규칙이 이 스킬보다 먼저다:

| 시리즈 | 제목 틀 |
|---|---|
| 내모남불 (nmNN) | `<주제> 내로남불 <남/나 대비 훅> \| <속사포 말들> \| <뜨거운 말> \| 내모남불` — "내로남불"은 꼭 앞쪽 |
| 모답맨 (epNN) | `<뜨거운 말> <아이 질문형 훅> <A·B 차이 3분 정리> \| 모답맨` |
| 이게 모예요? (imNN) · 모덕후 (mkNN) · 모 아니면 도 (mdNN) | 각 시리즈 문서 (`qna/docs/…`) 의 제목 규칙 |
| lab · shortube · funtube · fairy | 각 프로젝트 CLAUDE.md 의 업로드 규칙 (shortube 는 COMPLIANCE_GUIDE 도) |

- 길이: 한국어 제목 **100자 안**, 앞 40자 안에 핵심 말이 다 보이게 (모바일에서 잘린다).
- 영어 제목 100자 안, 직역 말고 검색될 말로 (예: "Double Standards", "Noisy Neighbors").
- **쇼츠 제목:** 40자 안 훅 + `#<뜨거운 말> #<시리즈 말> #shorts`. 쇼츠마다 다른 훅 (같은 제목 반복 금지).
- 민감한 단어 · 실명 · 상표 · 지역명 · 가격은 제목에 쓰지 않는다 (채널 규칙).

## 4. 해시태그 · 태그

- **해시태그:** 설명 맨 끝에 3~6개. 첫 3개가 제목 위에 뜬다 → ① 뜨거운 말 ② 주제 말 ③ 시리즈 말(#내로남불 · #모답맨). 15개를 넘기면 유튜브가 전부 무시한다.
- 조사 표의 "상위 영상이 많이 쓴 해시태그" 에서 주제에 맞는 것만 고른다. 남의 채널 이름 · 프로그램 이름 해시태그는 쓰지 않는다.
- **태그:** 표의 "태그 후보" 에서 시작해 주제와 안 맞는 것을 빼고, 시리즈 · 채널 말(내모남불 · 모답맨 · 모라구)을 넣는다. 합계 500자 안.

## 5. upload.md 에 남기기

seo 칸 아래에 (기존 편 `qna/content/nm05-office/upload/upload.md` 모양 그대로):

```
- 제목: …
- 영어 제목: …
- 설명: (훅 2줄 → ✔ 정리 → {CHAPTERS} → 시리즈 소개 → ※ 주석 → 해시태그)
- 영어 설명: …
- 태그: …
## 쇼츠
| 파일 | 제목 |
```

`- 제목:` 줄이 있어야 `seo-check` 가 통과한다. 그다음에 업로드 절차(각 프로젝트 CLAUDE.md · 메모리 studio-upload-chrome)로 간다.

## 6. 올린 뒤 (며칠 뒤 선택)

조회수가 낮으면 같은 조사 표에서 다음 후보로 제목을 바꿔 본다. 바꾼 제목과 날짜를 upload.md 업로드 기록에 적는다.
