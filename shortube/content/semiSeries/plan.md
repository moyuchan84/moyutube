# [market] 반도체 시리즈 기획 — 실적 vs 주가, 거품인가 (후보 5편 + 1편 상세)

- 날짜: 2026-10-19 / 대표 키워드: **반도체 영업이익 전망, AI 거품, 3배 레버리지, 메모리 사이클**
- 선정 근거: 사용자 지정 주제 (2026-10-19: 삼성 · 하이닉스 · 마이크론 · TSMC · 장비사, 3배 레버리지, 지수 PER, 영업이익 2020년대~28·29년 흐름, AI 반도체 거품 여부)
- **주제 선정 시점**: 2026-10-14~15 반도체 급락 직후 — 코스피 -7.57%(서킷브레이커, 10/15 종가 5,554.22), 하이닉스 -11.1%, 삼성전자 -9.5%.

## ⚠ 요청 전제 바로잡기 (영상에 넣는다)

1. **"28·29년 예상"** → 찾은 컨센서스는 **2028년까지**(에프앤가이드, 2026.07.10 기준). 2029년 증권사 추정은 확인 못 함 → 영상은 2028까지만. ASML이 "2029·2030 주문 문의가 있다"고 한 것은 *장비 수요 언급*이지 이익 전망이 아님.
2. **"거품인지 아닌지"** → 영상이 **결론을 내리지 않는다.** 말할 수 있는 건 "지금 숫자가 어디까지 와 있나 + 낙관/회의 양쪽 근거를 같은 비중으로". 제목에 "거품이다/아니다" 단정 금지.
3. **"3배 레버리지"** → 상품 소개 · 권유가 아니라 **이번 급락에서 실제로 일어난 일**(기초지수 -4.30% → SOXL -13.35%)만 숫자로. "사지 마라/사라" 금지.
4. **"PER"** → 현재 SOX · 개별 PER은 **오늘 기준 출처 확보 못 함**(마이크론 선행 PER ≈10배 vs SOX 평균 27배는 2026.05.31 블룸버그 보도 → 5개월 전 수치). 최신 PER 못 구하면 PER 장면은 뺀다. "PER 10배"를 오늘 값처럼 쓰지 않는다.
